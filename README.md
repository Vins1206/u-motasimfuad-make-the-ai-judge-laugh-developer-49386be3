# Make the AI Judge Laugh: Developer Excuses

One funny single-line excuse a developer gives when code breaks in
production — under 200 characters. A house judge model reads the excuses
two at a time in private blind rounds and keeps the one that lands the
bigger laugh.

## The line

> It worked on my machine because my machine has the .env file I swore I'd commit someday.

It turns the worn "works on my machine" excuse inside out: the real cause
was never the code, it was the uncommitted `.env` file living only on the
developer's laptop. Specific jargon, used right, self-owning, and it lands
in one breath.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set).
Pure Python stdlib, deterministic — every run writes byte-identical output.
